## 3. Task 明细（每 Task 三段齐全）

### T1 · 环境 + 摸底：两服务重启 + 矩阵定性 + 偏差审计表

> 依据 = 批 design **§9.5**（环境实测 D12）· **§4.3**（矩阵与 G3 定性）· **§4.6**（三探针口径 + G4 尺度）· **§9.2**（G6 收尾口径）。

1. **两服务重启到最新码**（design §9.5 实测：web dev 落后 5 个提交、API 落后 6 小时）——
   web：`lsof -nP -iTCP:5173 -sTCP:LISTEN -t | xargs -r kill` ⇒ `bun run --filter=@ai-asset-hub/web dev`；
   API：同法（端口 3000）。重启后复验三证：dev 200 · API 活 · 浏览器遥控口在线。
2. **全态矩阵定性**（§4.3）：逐页核 13 页 × 4 态，**清零「待核」**——重点两处候选：
   `/dashboard/publish` 载态（资产列表拉取处是否裸等）· `/admin` 空态（i18n `trend.empty.*` 与页面级 0 的不一致）。
3. **偏差审计表**（§4.6）：跑三探针（越轴值 / token 消费者 / 类串重复），越轴值逐条归三类（**在轴** / **已登记设计值** / **真越轴**），
   真越轴再按 G4 只修两类（同类页不一致 · 查无出处）。
4. **「前」读数落盘**（T9 比对用）：越轴唯一值数 / 命中数、类串重复数、token 全零消费数。

**断言 / 门禁**：① 三证复验输出留档 ② 矩阵**零「待核」**、逐格有归类（有 / 缺且该有 / N/A + 理由）③ 偏差表逐条带 `file:line` + 归类
④ 本包 `typecheck` + `lint` + `biome check` 绿（确认基线干净）。

### T2 · 前端：探针切片出「改前」图 + 几何读数表

> 依据 = 批 design **§4.1**（切片 S1–S4）· **§4.2**（物料与呈现）· **C1**（视口 1440×1100）· **C2**（命名）· **C3**（几何读数项）。

1. 切片：**S1** 共享壳（侧栏 + 顶栏）· **S2** `/admin/assets` · **S3** `/admin` · **S4** `/dashboard/publish`。
2. 每切片按相关态出图（正常 / 空 / 载 / 403 中该面存在者），**改前图**命名照 C2（`2026-XX-XX-m4b8-<切片>-<态>-before.png`）。
3. 几何读数表：表格表头高 / 行高 / 单元格内距 · 抽屉宽 · 卡片间距与圆角 · 主按钮高 · 侧栏展开宽 · 顶栏高（真浏览器计算值）。
4. 截图走浏览器遥控（CDP），视口显式设桌面档；**作废图即删**。

**断言 / 门禁**：① 图文件存在且非空（尺寸校验，非 0 字节）② 读数表 C3 各项齐全且为计算值（非类名推断）
③ 探针期间 `NO JS ERRORS` ④ 图名含 `before` 且与切片/态一一对应。

### T3 · 前端：切片打磨 + 三判停点

> 依据 = 批 design **§4.1**（切片 S1–S4）· **§4.2**（三判口径 D4）· **§4.4**（两层留痕 C5）· §4.5（不通只调 token 层，不动组件结构）。
> ⚠️ **口径补全（T2 收尾）**：三判必须有「**打磨后**」的物料才可判 ⇒ 本 Task **先做切片面的打磨**（= T4/T5 的切片子集），再出「改后」图与 T2 成对，然后停等口令。

1. **切片打磨**：共享壳 3 件（`AppShell` / `TopBar` / `SideNav`）+ S2 `/admin/assets` · S3 `/admin` · S4 `/dashboard/publish` 的相关件与页面 —— 逐项「**改前值 → 改后值 → 依据档位**」留痕。
2. 出「改后」图（同切片 · 同态 · 同视口 1440×1100）+ 几何读数表 → 附 `open` 命令 + dev 实机地址给用户。
3. **等逐项口令**（气质 / 密度 / 类型色）；通过项记 N/A。
4. **不通项** ⇒ 只改 token 层（`src/styles/aih-theme.css`；官方层 `index.css` 不手改），**重出该项的图**复判。
5. 三判结论与调参留痕写入证据文件。

**断言 / 门禁**：① 切片「改后」图与 T2「改前」图**一一成对** ② 三判逐项口令有留档 ③ 若调 token：越轴扫描**无新增**、`typecheck` + `lint` + `format:check` 绿
④ 组件结构零改动（`git diff --stat` 不含组件层级变化）⑤ `ui/shadcn/**` 零改动（P2）。

### T4 · 前端：共享件层打磨

> 依据 = 批 design **§4.4**（分层与留痕 C5）· **§3.2**（改造件表）· **§4.6 对照档位**（§4.4 真值）。

1. 先出**影响面清单**（每件被哪些页消费）——改一处全站生效，避免逐页返工。
2. 逐件打磨（顺序 = 影响面大到小）：壳 3 件（`AppShell` / `TopBar` / `SideNav`）→ 表格族消费侧（`DataTable` 的 `density` / 载态形态使用是否得当，**件本体不覆盖外观**）→ `console/Drawer`（宽 560）→ `console/StatusPill`（资产三态 / 版本八态语义色）→ `console/PageHeader` / `console/FilterBar`。
3. 逐项留痕：**改前值 → 改后值 → 依据档位（§4.4 出处）**。

**断言 / 门禁**：① `git diff --name-only` **不含** `apps/web/src/components/ui/shadcn/**`（官方件零改动 · P2）
② 越轴扫描无新增（P1）③ 同类件同形（几何比对）④ 本包 `typecheck` + `lint` + `format:check` 绿。

### T5 · 前端：页面层打磨
