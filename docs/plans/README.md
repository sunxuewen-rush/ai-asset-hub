# plans/ —— 计划层

存放**实现任务清单**（「怎么一步步做」+ 验收断言），与设计层/规范层隔离。

- 命名：`<里程碑>-<主题>.md`（如 `M1-platform.md`）
- 粒度：文件级任务 + 验收断言（命令/测试/断言），完成 = 断言为真
- 规则：Task 引用设计文档 §N；计划中冒出现未定决策 → 停下回设计层
- 里程碑完成报告/复盘：落 `docs/plans/<里程碑>-report.md`（如 `M1-report.md`），
  与计划同目录不新建层（质量审计/验收回顾/遗留项）
- 里程碑出口标准见 `docs/00-product-direction.md` §5（design ≥9 + plan 全绿 + 验证通过）

引用链单向：plan → design → 规范 §N（引用不复制，防漂移）。
