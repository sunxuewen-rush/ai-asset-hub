# plans/ —— 计划层

存放**实现任务清单**（「怎么一步步做」+ 验收断言），与设计层/规范层隔离。

- 命名：`<里程碑>-<主题>.md`（如 `M1-platform.md`）；拆批里程碑用 `M4b-<n>-<主题>.md`
- **批 plan**：头部写「前置：M4b-<n-1> ✅」；序与依赖以**主 design** §2.3 为唯一源；批间门 = 上一批**出口五件**全绿才启下一批（`批 design 8 维 ≥9 定稿` + `批 plan Task 全绿` + `五门禁` + `dogfood/观感` + **`整体审计`**——收尾全仓覆盖式扫描，findings 逐条登记 + 处置；口径见 `docs/00` §5/§7 ②）
- 粒度：文件级任务 + 验收断言（命令/测试/断言），完成 = 断言为真
- 规则：Task 引用设计文档 §N；计划中冒出现未定决策 → 停下回设计层
- 里程碑出口标准见 `docs/00-product-direction.md` §5（design ≥9 + plan 全绿 + 验证通过）

引用链单向：plan → design → 规范 §N（引用不复制，防漂移）。
