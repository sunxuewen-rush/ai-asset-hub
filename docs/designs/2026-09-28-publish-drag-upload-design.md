## 1. 背景与依据（三方实证 · 2026-09-28 实测）

**用户诉求**：发布页支持把 zip **拖进**上传区（不必先点按钮再在系统对话框里找文件）。

**同族仓做法实证**（用于确认「这是既定做法、且不需引库」）：

| 仓 | 上传控件 | 拖拽支持 | 上传库 | 存储/通道 |
|---|---|---|---|---|
| **ClawHub**（`24-clawhub`） | 原生 `input[type=file]` + 虚线空态 | **有**（手写 `onDragOver`/`onDrop`，`src/components/PackageSourceChooser.tsx:194/199/300/305`；发布页 `src/routes/skills/publish.tsx:853`） | **零** | Convex 文件存储（`storage.generateUploadUrl()` → 前端上传 → `storage.store(blob)`） |
| **OpenWork**（`02-lux-work`） | 原生 `input[type=file][multiple]` | **有**（手写，`apps/app/.../composer/composer.tsx:1432 onDragOver` · `:1443 onDrop` · `:1465 input`） | **零** | 自研服务端文件读写（含 artifact 下载） |
| **AIH（本仓）** | 原生 `input[type=file]` + **官方 `Empty` 全配方** | **无**（`Publish.tsx` 零拖拽事件） | **零** | 自研 ObjectStorage + 原包 `bundle.zip` |

**结论**：三仓在「**原生 input + 零上传库**」上完全一致（团队既定做法）；差异仅在 **AIH 缺拖拽** ⇒ 本增量 = **补齐该项，并对齐另两仓的实现方式（手写事件，不引依赖）**。

## 2. 范围与非目标

**做**：发布页 ② 段支持把文件**拖入**即完成选择（拖拽区 = ② 段 `<FieldSet>`，**常驻**；v1.2 决策⑥）· 与点击选择**同一条落点**（同一个 `input.files` 通道）；已选态拖入 = 替换所选文件。
**不做**：页面级/全窗口拖放 · 整包自动解压 · 多文件批量上传 · 目录拖入 · 服务端任何改动 · 新增第三方依赖。

### 3.1 `slug` 自动预填：与 ClawHub 的逐行对照 + 差异清单（T6）

**照搬基线（`24-clawhub/src/routes/skills/publish.tsx` 实测）**：

```ts
// :623-643 选完文件后（applyExpandedFiles）
const folderName = getSharedTopLevelFolderName(report.files);   // 所有文件的共同顶层目录名（无则 null）
const nextSlug = slugFromFolderName(folderName);
if (nextSlug && !dirtyFields.slug && !trimmedSlug) setSlug(nextSlug);   // 空 ∧ 未改 ⇒ 才填

// :1394-1402 派生规则（逐行照搬对象）
function slugFromFolderName(name: string) {
  return name.trim()
    .replace(/([a-z0-9])([A-Z])/g, "$1-$2")   // camelCase 拆词
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")              // 非字母数字 → '-'
    .replace(/^-+|-+$/g, "")                  // 去首尾 '-'
    .replace(/-{2,}/g, "-");                  // 折叠 '--'
}
```

**差异清单（AIH 与 ClawHub 的输入形态不同 ⇒ 必须显式列出）**：

| # | 差异 | 理由 |
|--:|---|---|
| ① | **来源**：ClawHub 取「所有文件的**共同顶层目录名**」（它有 `webkitRelativePath`）；AIH 取「**zip 文件名**（去扩展名）」 | AIH 收单包、浏览器不给 zip 内部路径；要拿包内顶层目录名须**客户端解 zip**（引依赖或自写解析 ⇒ 过度工程），或改「上传成功后再回填」（体验倒退） |
| ② | **长度**：AIH 在规则末尾加「截断 64 → 再去尾部 `-`」 | ClawHub 无此步（其上限由别处兜）；AIH 协议 `slugSchema` 硬上限 64（`packages/protocol/src/slug.ts`） |
| ③ | **输入预处理**：AIH 先 `replace(/\\.zip$/i, '')` 去扩展名 | ClawHub 输入本就是目录名（无扩展名） |
| ④ | **换包刷新**：AIH 在「当前值仍等于上次自动派生值」时**随新文件名刷新**；ClawHub 因 `!trimmedSlug` 已为假而**不刷新**（旧名残留） | AIH 是「单包选择」语义：换了包，标识名不符实属缺陷；本差异为**有意改进**，已在 §5 断言 ⑬ 覆盖 |
| ⑤ | **displayName 预填**：**不照搬** | ClawHub 顺带预填显示名（`displayNameFromFolderName`）；AIH 资产无该字段（名字来自包内 `SKILL.md`）⇒ 不适用 |

## 4. 边界与失败面

| 场景 | 期望行为 |
|---|---|
| 拖入**多个**文件 | 取第一个；若第一个非 `.zip` ⇒ 行内提示 + 不选中 |
| 拖入**非 zip**（如 .md / 目录） | 行内提示（i18n）；不选中、不进入执行中态 |
| 拖入**目录**（浏览器给出 0 字节条目或无 `type`） | 同「非 zip」处理（按扩展名判定） |
| 上传中拖入 | 忽略（D6①）；既有进度/取消不受影响 |
| 拖入后在区内移动 | 高亮保持（`dragleave` 计数法）；拖出区外高亮消失 |
| 拖拽取消（Esc / 拖出窗口） | 高亮复位，无副作用 |
| 双击/单击虚线区 | 仍打开系统文件对话框（D5①，键盘可达） |
| 触屏设备 | 无 drag 事件 ⇒ 走点击路径（无需特判） |
| **模式自动判定命中/未命中** | 命中 ⇒ 切「已有」+ 选中该资产 + 版本号 `latest+1`；未命中 ⇒ 保持「新建」+ `1.0.0`（D15/D16） |
| **包名带尾巴**（`skill-ucts-report-v2-final.zip`） | 派生 slug 与既有资产**不相等** ⇒ 判为「新建」；若服务端返回 409 ⇒ 既有行内提示兜住（**不做模糊匹配** —— D15 明确不猜）|
| **「我的资产」超过 100 条** | 一次性查询 `limit=100`；未被这 100 条覆盖的同名资产 ⇒ 判为「新建」⇒ 由 409 兜住（不为此加分页） |
| **查询失败 / 超时** | 静默保持「新建」（D17①）；不弹提示、不阻塞选包 |
| **用户手动切过模式** | 再选包/换包**不再自动切**（`modeTouched`）；点 × 也不回切 |
| **自动切到「已有」后点 ×** | 回「新建」+ 清选中与版本号回 `1.0.0`（与 slug 同族对称：自动来的随包走；用户手动切过的不动）|
| **未选文件时的 ②/③ 段** | **保持可见**（沿用 §4.2「未达前置的段保持可见」）· 面板状态显示「待办」—— 可见但待办，是有意为之 |
| **链失败（三跳任一）** | 右栏圆点落 **③ 发布 = 未通过**；字段级错误仍按停点归属（跳1 → 标识 / 跳2 → 版本号 / issues → 段落 Alert）—— 两者**有意解绑**（D19①）|
| **`?slug=` 深链** | 新 IA 下直接落在 ② 自识别（资产已选中 + 版本号已预填），① 上传段等用户给包 —— 深链语义不变（预选资产），只是位置从「①」变「②」|
| **点 × 移除已选包** | 回「未选态」（官方 `Empty` 重现）⇒ 可**重新点击选择**或**重新拖入**；本地提示与进度清零（D13①） |
| **移除后 slug 的去留** | 仍是自动派生值 ⇒ **一并清空**（下次选包重新派生）；用户手改过 ⇒ **保留**；「选用已有资产」支与 `?slug=` 深链 ⇒ **不动** |
| **上传中点 ×** | **无 × 可点**（D14①：该位置显示「取消上传」）| 
| **派生 slug 为空**（如 `我的技能.zip`） | slug **保持空**（不猜、不填占位）；文件仍正常选中；由用户手填（D11①） |
