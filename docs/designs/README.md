# designs/ —— 设计层

存放**阶段性设计文档**（记录「为什么这么做」= 阶段决策），与规范层隔离。

- 命名：`YYYY-MM-DD-<主题>-design.md`（日期前缀 + `-design` 后缀）
- 触发：里程碑内出现需拍板的设计块（技术选型/状态机/UX 线框）
- 骨架：8 段（元信息/修订记录/正文/接口变更总览/UI-UX 变动/线框图/引用文件/任务清单）
- 门禁：8 维自检 ≥9 → grilling → 重评 ≥9
- 合并铁律：同主题小迭代追加既有 design（bump 版本），不新建散文档

体系定义见 `docs/00-product-direction.md` §7。
