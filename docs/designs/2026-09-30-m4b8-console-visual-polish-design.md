### 4.4 打磨项分层与留痕（C5）

打磨 = 在**两个层**上分别改，逐项**改前/改后留痕**（值 → 值 + 落点 + 所属 §4.4 档位）：

1. **共享件层**：改一处、全站生效 ⇒ 先做（避免逐页返工）；改前必须先出「影响面清单」（哪些页消费该件）。
2. **页面层**：页面自有布局与间距（列宽 / 卡片间距 / 响应式档）。
3. **不做的事（显式）**：不改信息架构（列集合 / 段序 / 文案含义）· 不改交互语义（谁可点 / 提交什么）·
   不改 URL 与权限 · 不为「更好看」给某页单独发明一套样式（同类页必须同形）。
