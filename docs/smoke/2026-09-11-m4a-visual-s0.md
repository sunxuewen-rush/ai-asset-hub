| `SMOKE_SHOT_PREFIX=s0- bun docs/smoke/scripts/m4a-dogfood.ts` | ✅ **22/22 PASS + NO CONSOLE ERRORS**；截图 `docs/smoke/s0-{1..6}-*.png`（1440×900） |

**冒烟脚本修复（实证根因；属 harness 缺陷，非产品回归）**
- 现象：首跑 `FAIL 三中心 href 可达（侧栏导航）`。
- 根因（实测非推断）：连上该次运行遗留的 CDP tab 读实况 → 视口 **748×472** ⇒
  `useIsMobile` 判为移动端 ⇒ 侧栏退化为 **Sheet（不进入 DOM）** ⇒ 首页 `<a>` 只剩品牌链接（`/`）⇒
  断言条件 `['/skills','/mcps','/agents'].every(...)` 必然假失败。
  复现对照：390×844 / 767×900 → `hasThree=false`（侧栏不在 DOM）；800×600 → `hasThree=true`。
- 性质：该断言在 v0.15 由「首页入口 href」改判为「侧栏导航」后**从未实跑过**（「未实证断言」实例），
  本次首跑暴露。
- 处置：脚本加 `Emulation.setDeviceMetricsOverride` **1440×900 桌面**（断言与截图宽度确定化）——
  **未放宽任何断言**；移动端不在本里程碑范围（用户 2026-09-11「先不用考虑移动端」）。
- 附带踩坑：截图前缀变量是 **`SMOKE_SHOT_PREFIX`**（首跑误用 `SHOT_PREFIX` → 前缀为空 → 覆盖了 6 张
  历史里程碑截图；**已 `git restore` 完整还原**，新产物一律写 `s0-*`）。正确用法已写进脚本头注释。
