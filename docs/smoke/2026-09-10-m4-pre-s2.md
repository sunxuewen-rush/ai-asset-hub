## 1. 迁移 0006（`drop_namespace_domain`）实测

**手工重排自 drizzle-kit 生成稿**（三处修正，均已落盘 `apps/server/drizzle/0006_drop_namespace_domain.sql`）：

| # | 生成稿问题 | 处置 |
|---|-----------|------|
| ① | `DROP TABLE namespace CASCADE` 排在 `DROP CONSTRAINT …_namespace_id_fkey` **之前** → 约束已被级联删除，后续 ALTER 报错（与 0005 同类顺序坑） | 重排为：校验 → 删索引/约束/列 → 建新索引与唯一键 → 最后删表 |
| ② | 缺 design §5 **P2 前置校验** | 补 `DO $$` 块：跨空间同名 slug → `RAISE EXCEPTION` 中止并输出冲突清单（`@ns/slug` 列表） |
| ③ | 唯一键形态 | 保持 CONSTRAINT 形态 `ADD CONSTRAINT uq_asset_slug UNIQUE(slug)`（与 schema 快照一致；改写成 `CREATE UNIQUE INDEX` 会让后续 `drizzle-kit generate` 误判漂移） |

**执行结果**（dev 库 `docker compose` PG）：

```

asset 列                             → 12 列，无 namespace_id
asset 唯一约束                        → uq_asset_slug UNIQUE (slug)（原 uq_asset_namespace_slug 已删）

```
