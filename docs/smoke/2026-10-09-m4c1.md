## 6. 关键实测（本批硬证）

- 登录端点真值：自绘 `POST /api/auth/sign-in/aih` ⇒ **真 404**；官方 `/sign-in/username` = 唯一口令登录入口
- 防枚举四态同码：存在+错口令 / 不存在（合规名）/ 目录账号错口令 / 空口令 ⇒ **一律 401 `INVALID_USERNAME_OR_PASSWORD`**
- 错误码集合：`apps/server/src/auth/errors.ts` **12 → 8**（删 `invalid_credentials` / `ldap_denied` / `user_disabled` / `user_pending`）
- 自助注册默认关闭：`sign-up/email` ⇒ **400 `EMAIL_PASSWORD_SIGN_UP_DISABLED`** + **零建号**
- 口令流转：登录响应体与审计明细**零明文口令**（审计用例 ⑫ 断言）
- 三账号真 200（官方端点 + 官方会话 cookie）：见 T6 记录
