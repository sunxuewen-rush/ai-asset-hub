## 一、落地内容（三处 + 一处底色）

| # | 变更 | 用户拍板 | 落点 |
|---|------|:--:|------|
| ① | **整个 hero 去卡**：`<Card>`（官方件：白底 + border + `rounded-xl` + `shadow-sm`）→ `<div>` ⇒ 标题「AI X Hub」/ 副标 / 搜索行 / 统计条**全部直接落在页面底色**上（`body` 的 `--gradient-page`）；撑满 `flex-1` / 居中 / 内距 `px-10 py-12` / rise 动画**四项不变** | **B** | `Hero.tsx` |
| ② | **搜索行改官方 `InputGroup` 框内形态**：`<InputGroup>` + `InputGroupInput` + `InputGroupAddon(align=inline-end)` + `InputGroupButton`；⇒ **M4b-1 批 design §6.2 的 D′ 项「输入框内按钮改 `InputGroup`」收口落地**（原「并列 ⇒ 官方硬规则 5 不适用」豁免作废） | **1** | 同上 |
| ③ | **胶囊化 + 单放大镜**：`rounded-full`（覆盖官方默认 `rounded-md`）· 高 `h-11` = **44px**（Google 首页同档）· **左侧 addon 整块撤除**，放大镜**只出现一次**且落**右侧**当提交钮（`size="icon-sm"` = 32×32 · `variant="ghost"` · `type="submit"` · `aria-label`=「搜索」） | **1** | 同上 |
| ④ | 底色 **保持透明**（不叠白底/投影，与「去卡」后的通透观感一致） | **A** | 同上 |

**③ 的设计依据（避免"两个放大镜"）**：Google 两种范式 ——
**首页**大框 = 左放大镜（提示）+ 右侧**不同语义**图标（语音/镜头）；**结果页**顶部框 = **左侧不放**，右侧放大镜**即提交**。
⇒ 规则：一个框内放大镜只出现一次；承担提交时归**右侧**。
