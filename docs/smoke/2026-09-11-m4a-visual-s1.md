## 8. 登记项（未覆盖 / 需后续）

1. **翻页**：dev 库资产数 < limit 20 ⇒ 分页交互不可现场实证（已加「正当缺席」反向断言）；需 >20 资产的环境。
2. **子标签行 / 多标签 OR 未入 harness 自动化**：harness 无管理员凭据（`POST /api/labels` 需 SUPER_ADMIN）
   ⇒ 本轮以「网络层 stub + 多值 URL 直载」实证；如需自动化，需给 harness 注入管理员会话（**新依赖凭据**，待拍板）。
3. **细滚动条「6px」名实不符**（迁移前即如此）：Chrome 标准属性（`scrollbar-width`/`scrollbar-color`，可继承）
   优先于 `::-webkit-scrollbar` ⇒ 实测容器 15px / 文档级 11px（thin）；对照实验证明与迁移前逐位一致。
   要真 6px ⇒ 去掉 `html` 两条标准属性（**观感选择，待你定**）。
4. **3 处文档仍引用已删旧层文件**（design 目录树行 · m4b design L29/L670）→ **T26 converge** 处置
   （M4b 照旧引用会指向不存在的文件）。
5. **M2 design 失效内容无「作废」标注** → T26 converge 加标注行（正文不改）。
6. **沙箱教训（写入技能笔记）**：长寿命 browser 会话多次注入样式/stub 后会出现**渲染与 URL 状态不一致**
   的假象（同一流程在**全新 tab** 一次通过）⇒ 判定应用 bug 前先**换新 tab 复现**；另：探针读色值前先关过渡。
